# VWZ 安全分析状态

日期：2026-09-28
状态：H-1 缺口（VMQ-SPARSE → LWE 归约）完全未证明
结论：不跑 lattice-estimator（理由见下）

## 参数规格（实验性研究线）

| 参数 | 值 | 备注 |
|------|-----|------|
| q | 3329 | 同 ML-KEM-768 |
| k | 8 / 16 / 32 | 推荐参数 |

| Tensor OWF lower bound (k=8) | ≈73 bits | 远低于 NIST-1 (128-bit) |

## 为什么不在 LWE 框架下跑 estimator

1. **H-1 完全未动**。跑出来的 β 是「如果 VWZ 等价于 LWE(n≈256, q=3329)」的条件数字——
  而这个「如果」本身就是要证明的事。条件结论没有独立价值。
2. **Tensor OWF lower bound 已标出 ≈73 bits**（k=8）。这暗示实际安全性可能远低于
  同维度 LWE 的预期值。跑 estimator 不解决这个 gap。
3. **rank-1 已被完全攻破**（多项式时间伪造）。历史表明 VWZ 的安全性论证
  不能靠与 LWE 的类比。

## 重启条件

- 新安全模型提出，或
- H-1 归约有关键进展，或
- 找到 VWZ 与某个已知困难假设的非平凡等价

在此之前，VWZ 的安全分析不进入 estimator 阶段。
